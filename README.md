# Riiddev — Curious by Design

A small personal portfolio inspired by playful editorial illustration, pastel sea colors, bold typography, and pixel-like details. The portfolio presents Riiddev as a curious developer who is learning through experiments—not as someone claiming expertise.

## Run locally

No build step or package installation is required. Open `index.html` in a browser, or run a local static server such as VS Code Live Server.

## Files

- `index.html` — semantic page sections and project content.
- `styles.css` — responsive layout, custom CSS project illustrations, interaction states, and reduced-motion styles.
- `script.js` — mobile navigation, scroll progress, reveal-on-scroll, gentle portrait tilt, and contribution-image fallback.
- `assets/riiddev-portrait.jpg` — temporary portrait based on the supplied illustration.

## Replace the portrait

Replace `assets/riiddev-portrait.jpg` with a new square image using the same filename. The portrait is styled as a circular crop, so no code changes are needed.

## Hosting

This is a static site with no backend, paid service, API key, or dependency installation. It can be hosted on GitHub Pages or another static host. If using GitHub Pages, select the `main` branch and `/ (root)` as the publishing source in the repository's Pages settings.

## Featured projects

The portfolio links to source repositories for NASIB +62, Riiddev Agent HQ, StudyWithMbah, Latveria, and Nulis Esai by Parthoo.
